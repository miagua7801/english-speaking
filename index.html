마이크·음성 테스트

학교 크롬북에서 이 페이지를 열어 1번부터 5번까지 차례로 눌러 보세요. 모두 초록색이면 롤플레이 웹앱을 만들어도 됩니다.

  • 0. 브라우저·주소 확인대기
  • 1. 영어 음성 재생 (TTS)대기
  • 2. 마이크 권한 · 입력 감지대기
  • 3. 영어 음성 인식 (STT)대기
  • 4. 결과 이미지 저장 (PNG)대기

1. 영어 음성 재생

아래 문장이 영어로 들리면 성공입니다. 소리가 나지 않으면 크롬북 음량을 확인하세요.
What kinds of movies do you like?
음성 목록을 불러오는 중…

2. 마이크 권한 · 입력 감지

버튼을 누르면 권한 창이 뜹니다. [허용]을 누른 뒤 말해 보세요. 막대가 움직이면 성공입니다.

3. 영어 음성 인식

버튼을 누르고 있는 동안 말합니다. 아래 문장을 크롬북에서 20cm 거리에서 말해 보세요.
I like action movies.
인식된 문장이 여기에 표시됩니다.
방법 3가지 — ① 버튼을 누르고 있기 ② 스페이스바를 누르고 있기 ③ 위 칸을 체크하면 한 번만 눌러도 되고, 말이 끝나면 저절로 멈춥니다.

4. 결과 이미지 저장

버튼을 누르면 PNG 파일이 내려받아집니다. 실제 앱에서 결과 카드를 저장하는 방식과 같습니다.
